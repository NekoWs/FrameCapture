# FrameCapture 旧版更新入口

主项目与源码：[NekoWs/NekoCapture](https://github.com/NekoWs/NekoCapture)。

本仓库仅为 FrameCapture 客户端提供兼容更新清单与升级包。更新后程序名称为 **NekoCapture**，配置、快捷键和已下载组件会保留。

请直接从 [NekoCapture Release](https://github.com/NekoWs/NekoCapture/releases/latest) 获取新版安装包。

兼容更新每小时同步，也可手动运行 Legacy update 工作流。兼容安装包与主仓库安装包字节相同，沿用原签名公钥验证更新。
